# 08 — 主幹化：逐字稿驅動分段

**要做出什麼：** 一支影片的分段依據是「講者講到哪裡換了話題」，
而不是「鏡頭切了」。每個 chunk 是一個完整的想法。

**Blocked by：** 07

**Status:** ready-for-agent

這是 v0.5 的核心改動。S3 的職責從「對齊」變成「分段」；
`Segment` 不再由 `Slide` 切換決定。

實作哪一個方案，**由票 07 的量測結果決定**，不是由本票預設。
SPEC 的 D-B 是量測前的預期，不是結論。
