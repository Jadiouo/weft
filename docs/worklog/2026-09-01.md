## 2. 使用者的架構批評，以及它的名字

> 「我拿一個東西去測驗，然後把測驗的結果當作它的先驗，再去驗其他來的東西。
> 這個就很奇怪啊。」

**這個診斷是對的，而且文獻裡有名字**：我們的 §5.4 量的是
**Source Faithfulness**（有沒有照著給它的東西講），而使用者要的是
**World Factuality**（講的是不是真的）。摘要評估的文獻明確寫著：
「有些對來源不忠實的輸出，事實上是正確的。」

**那正是 R39 §3.1**：Whisper 把「座標」聽成「做標」，S4c 自己改對了，
而我們的檢查判它「溯不到」——**我們在懲罰模型做對事**。

### 但修法的觸及面比想像小

| | 逐字稿 | 有原文可對？ |

| 中醫講經 ×4 | **人工字幕**（乾淨）| 有 |
| 機器人學、大问题 | Whisper（髒）| **沒有** |

**有原文可對的那批逐字稿本來就乾淨；髒的那批沒有原文。**

前人工作查了（retrieval-augmented ASR correction、contextual biasing、
forced alignment），共同點是**它們修的是逐字稿，不是驗證**——
這其實正合使用者說的順序：先錨定，再萃取。
