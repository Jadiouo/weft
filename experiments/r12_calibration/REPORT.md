# R12 校準：正向溯源門檻的逐型別實測

素材：`zIglvjoU9vo` 首跑輸出（2026-08-04）+ 手寫對照組
方法：比照 `docs/decisions.md` D1——每型別建「忠實 vs 幻覺」對照組，量分離度
判準：比照 D1，**分離倍數 <2x 即判該型別不可用單一門檻**，不調參數硬拉

---

## 結論（先講）

**containment 只對「經文原文」有鑑別力。** 其餘三型的忠實與幻覺分布重疊，
其中「口頭延伸」甚至**反轉**（忠實最低 0.090 < 幻覺最高 0.167）。

這不是門檻沒調好，是**指標不適用**。任何門檻不是擋掉忠實內容就是放行幻覺。

已做的處置：

1. **擴充具名實體的單位清單**——清單漏了週／天／種／成／公分等常見單位，
   導致「四種」「七成」「第五週」「二十一天」全部抓不到。補上後幻覺攔截
   從 5/12 升到 8/12，**誤報零增加**。
2. **逐型別的正向門檻**，但**不假裝它有鑑別力**：後三型的門檻降到只擋
   「與來源完全無關」的退化情形。
3. **明確記錄保護弱化**——防幻覺的責任移交給具名實體檢查與 §5.6 人工抽檢。

真實資料上的效果：溯源未通過從 **43.0% 降到 3.0%**，`needs_review` 解除。

| 階段 | block | 未通過 |
|---|---|---|
| 首跑（單一門檻 0.25） | 79 | 34（43.0%） |
| 修掉「來源為空」的 bug | 67 | 34 |
| + 逐型別門檻與來源長度比 | 67 | **2（3.0%）** |

剩下 2 筆的性質正確：1 筆**是真問題**（來源只有「講完好像就」5 個字撐不起
44 字的內容），1 筆是誤報（跨語言的忠實翻譯提到「九個月」，而英文投影片的
`slide_text` 沒有數字）。

## 1. 各型別的分離度

| 型別 | 忠實（min / 中位 / max） | 幻覺（min / 中位 / max） | 分離 | 判定 |
|---|---|---|---|---|
| 經文原文 | 1.000 / 1.000 / 1.000 | 0.133 / 0.133 / 0.133 | **7.50x** | 可用 |
| 白話解說 | 0.276 / 0.338 / 0.400 | 0.182 / 0.212 / 0.242 | **1.14x** | 不可用 |
| 口頭延伸 | 0.090 / 0.265 / 0.410 | 0.000 / 0.047 / 0.167 | **0.54x** | 不可用 |
| 圖表描述 | 0.000 / 0.101 / 0.231 | 0.000 / 0.000 / 0.175 | **0.00x** | 不可用 |

**連 D1 校準過的白話解說都掉到 1.14x。** 原因是這次的幻覺樣本更難：

> 「一月為胞，精血凝也，此說與《黃帝內經》素問篇的五運六氣之論互為表裡。」

前半是**真引文**，後半是編造。真的那半把 containment 撐到 0.242。D1 的幻覺
是整段虛構（≤0.154），太好擋。**部分編造嫁接在真材料上**才是真實的幻覺形態。

## 2. 為什麼 containment 在這三型上失效

### 2.1 口頭延伸：口語 → 書面的結構性落差

來源是逐字稿，充滿重複與贅詞；block 是壓縮後的書面語。

| | 內容 |
|---|---|
| 來源 | 「就是有徵兆了有一點人的樣子了你這個房子要裝潢房子是給什麼住的 給人住的…」 |
| block | 「講者用裝潢房子比喻懷孕第二個月：房子要按住的對象來裝潢…」 |

詞彙落差是**語域差異**造成的，與忠實與否無關。

### 2.2 圖表描述：描述結構 vs 內容詞

block 描述的是**版面**（「左側標註時間軸，右側標註功能漸齊備」），
`slide_text` 是**內容**（經文逐月列表）。兩者本來就不共用詞彙。

### 2.3 跨語言：結構上必為 0

實測案例：投影片是英文，block 是中文翻譯。

| | 內容 |
|---|---|
| 來源 | `Cleavage / Blastocyst / Implantation / Gastrulation / Turning / Organogenesis` |
| block（忠實） | 「包含卵裂、胚泡形成、著床、原腸胚形成、轉向及器官形成等階段」 |

**忠實與幻覺都是 0.000。** containment 在跨語言下沒有任何鑑別力。

### 2.4 來源短於 block 時的數學上限

containment 以 **candidate** 長度正規化。來源比 candidate 短時，分數有上限：

| | 內容 | 長度 |
|---|---|---|
| 來源 | 「意導氣 氣成形 / 先天之氣:腎氣」 | 12 字 ≈ 11 bigram |
| block（忠實） | 「意念引導氣的運行，氣進而形成形體。在先天狀態下，這股氣被稱為腎氣。」 | 33 字 ≈ 32 bigram |

理論上限 11/32 ≈ **0.34**，實測 0.125。文言文的簡短句被展開成白話時必然如此。

## 3. 具名實體檢查才是能推廣的那道

| 型別 | 抓到的幻覺（原本） | 抓到的幻覺（擴充單位後） | 誤報 |
|---|---|---|---|
| 口頭延伸 | 0/5 | **3/5** | 0/4 |
| 圖表描述 | 2/4 | 2/4 | 1/4 |
| 白話解說 | 2/2 | 2/2 | 0/2 |
| 經文原文 | 1/1 | 1/1 | 0/2 |
| **合計** | **5/12** | **8/12** | **1/12** |

**修正**：原本的單位清單是 `年月日歲個張條章卷篇位次倍分`，漏掉

- 時間：週、周、天、旬、季、時、秒、世紀
- 計數：種、類、項、點、步、層、級
- 比例：成、度、%
- 度量：公分、公尺、公里、公斤、公克、毫升、毫米

多字單位必須排在單字之前（`公分` 要在 `分` 之前），否則會被先吃掉。

### 仍然抓不到的：純質性編造

4/12 的幻覺**完全沒有具名實體**：

- 「懷孕期間父母的心境與行為會影響投胎的靈識，建議孕婦保持愉悅、閱讀或聽經」
- 「投影片右下角以紅框標出第七月的七精開竅，並附有一張肺臟解剖圖」
- 「圖表下方以長條圖比較各階段的細胞分裂速率，縱軸為分裂次數，橫軸為月份」

沒有編造的數字或書名，只有編造的**陳述**。containment 與具名實體檢查
**都抓不到**。這是 §5.4 目前真正的缺口。

## 4. 採用的設定

```yaml
provenance:
  min_similarity_by_type:
    經文原文: 0.60   # 唯一有鑑別力者；實測忠實為 1.000、幻覺 0.133
    白話解說: 0.15
    口頭延伸: 0.05   # 只擋與來源完全無關的退化情形
    圖表描述: 0.02   # 跨語言時結構上就是 0
```

後三型的數值**不是校準出來的門檻**——校準的結論是「這個指標在這裡沒有
鑑別力」。它們的作用只剩下擋掉「block 與來源毫無關係」這種退化情形。

## 5. 過程中的一次矯枉過正（測試抓到的）

我一度把後三型的 containment **全部停用**（設 0.0），理由是「分布重疊，
任何門檻都無效」。既有測試 `test_content_taken_from_wrong_source_is_caught`
立刻紅燈——它測的是「block 宣稱來自投影片，內容卻只在逐字稿裡」。

那個案例的 containment 約 **0.06，低於所有忠實樣本**（最低 0.125 / 0.090）。
也就是說 containment 分不出「忠實 vs 部分編造」，但**分得出「引錯來源」**。
這是兩種不同的失敗模式，我不該一起停用。

最終設定因此區分兩件事：

| | 擋得到 | 擋不到 |
|---|---|---|
| containment 低下限 | 引錯來源（provenance 指錯地方） | 部分編造（真引文接上編造） |

**圖表描述仍然無法設任何下限**——跨語言時忠實者本身就是 0.000。

## 6. 為什麼下限是這些數字（不是調到剛好通過）

修正後真實資料的未通過率是 **7.5%**，仍超過 §5.4 的 5%。逐一檢視這 5 筆：

下限取在**實測的忠實最低值之下**，而不是取在「能讓未通過率低於 5%」的位置：

| 型別 | 實測忠實最低 | 採用下限 | 依據 |
|---|---|---|---|
| 經文原文 | 1.000 | 0.60 | 唯一有鑑別力者，留大餘裕 |
| 白話解說 | 0.125 | 0.10 | 略低於忠實最低，只擋引錯來源（≈0.06） |
| 口頭延伸 | 0.090 | 0.05 | 同上 |
| 圖表描述 | **0.000** | 0.0 | 跨語言時忠實者就是 0，**無法設下限** |

**來源長度比 0.15 未經校準。** 觀測到的失敗只有 n=1（比值 0.11），次低的
忠實樣本是 0.28（標題卡、文言文簡短句的展開）。0.15 取在兩者之間偏保守側。
累積更多真實資料後應重新校準——**這一條目前是軼事不是校準**。

## 6. 可能的改進方向（未實作）

1. **放寬來源窗口**（已實測）。口頭延伸取 segment ±2 的逐字稿，未通過率
   從 55% 降到 38%，且救回的正是忠實樣本（`#037` 0.087→0.261）、
   沒救回逐字稿為空者。理由正當：S3 的邊界是**視覺**的，語意本來就會跨界
   （R10 移除語意吸附後更明顯）。
2. **圖表描述改用不同的檢查**。它的事實主張是「引用了哪些標籤」，
   應該只驗具名實體與標籤詞，不驗整體 containment。
3. **跨語言時比對翻譯後的來源**。需要翻譯步驟，成本待評估。
4. **對純質性編造，唯一有效的可能是第二個模型當裁判**（LLM-as-judge）。
   那要花額度，且與 R9 同樣有「同一個模型驗自己」的獨立性問題——
   得用**不同的**模型才有意義。
