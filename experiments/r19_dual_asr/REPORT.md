# R19：雙重驗證（SDD §4.2 策略 3）的可行性量測

素材：`zIglvjoU9vo`（有**人工**字幕當標準答案）
ASR #1：Whisper large-v3（R17）　ASR #2：Whisper medium（本實驗）

---

## 結論（先講）

**SDD 寫的策略 3 在這個語料上不存在——沒有獨立的 ASR 字幕軌可用。**

但雙重驗證的**機制本身有效**，前提是訊號要綁在術語上：

| 訊號 | 不一致率 | 錯誤 recall |
|---|---|---|
| 原始文字層級 | **90%** | —（等於沒有訊號） |
| **術語層級** | **39%** | **93%** |

兩套 ASR「一致地寫成同一個錯的東西」只有 **2/30**——
這是交叉檢查唯一抓不到的情形，比例遠低於我原先的擔心。

---

## 1. SDD 策略 3 在這個語料上不存在

`yt-dlp --list-subs` 實查：

**`zIglvjoU9vo`**——唯一非翻譯的字幕軌是 `zh-Hant`，**就是那份人工字幕**。
所有 `automatic_captions` 都是「X **from** Chinese (Traditional)」，
也就是**從人工字幕機器翻譯**出來的，不是獨立的語音辨識。

```
zh-Hans-zh-Hant  Chinese (Simplified) from Chinese (Traditional)
zh-Hant-zh-Hant  Chinese (Traditional) from Chinese (Traditional)
zh-Hant          Chinese (Traditional)      ← 人工字幕本身
```

**另外三支同講者的影片**（`q3iM-jlbQBA`、`XJXbSaenwnY`、`mMlQEpu6GRI`）：

```
has no automatic captions
has no subtitles
```

**什麼都沒有。**

也就是說這個語料只有兩種影片：有人工字幕的（YouTube 因此不跑 ASR，
只提供翻譯軌），與什麼字幕都沒有的。
**「自動字幕 + Whisper 交叉檢查」無從實施。**

SDD §4.2 策略 3 需要改寫——第二個來源必須是我們自己跑的第二個 ASR。

---

## 2. 用第二個本地 ASR 取代

用 Whisper **medium**（1049 cue，1.3 分）當 ASR #2。

**medium 與 large-v3 同家族，不是真正獨立。** 這是刻意的保守選擇：
同家族**共享錯誤模式**，所以「兩者一致地錯」的比例是真正獨立系統的**上界**，
交叉檢查的 recall 是**下界**。若連這樣都有效，換成獨立系統只會更好。

---

## 3. 訊號必須綁在術語上

以人工字幕為標準答案，對 `term_index` 中在逐字稿出現過的 **72 個術語**，
取其時間窗（±2.5s）比對兩套 ASR 有沒有寫出該術語：

| 情形 | n | 交叉檢查 |
|---|---|---|
| 兩者都對 | 42 | — |
| 只有一邊錯 | 10 | **抓得到** |
| 兩者都錯、寫得不同 | 18 | **抓得到** |
| 兩者都錯、**寫得一樣** | **2** | **抓不到** |

- **錯誤 recall = 28/30 = 93%**
- **不一致率 = 39%**（會被送去人工複核的比例）

抓不到的那 2 個是同一處：

```
承其宿業 → 兩套都寫成「…不是那個檸檬成其樹葉萬物所有東西會生在這裡…」
```

這是最危險的形態——兩套系統一致地錯，**看起來像互相印證**。
但 2/30 的比例遠低於我在 R17 的擔心。

### 對照：原始文字層級的不一致率是 90%

同樣的時間窗，若直接比較兩套 ASR 的**整段文字**：

```
828/925 = 90% 的時間窗不一致
```

**幾乎每一句都要人看，等於沒有訊號。** 兩套 ASR 在贅詞、標點、
分段上本來就會大量不一致，那些不一致與正確性無關。

**這是本報告最重要的設計結論**：雙重驗證不能拿「文字不一致」當訊號，
必須問「**這個術語兩邊都寫對了嗎**」。

---

## 4. 術語清單從哪裡來

上面用的是 `term_index`，但那是**人工字幕**跑出來的結果——
無字幕影片沒有這個東西。實測 72 個術語中：

- **38 個（53%）** 可單從 `slide_text` 取得
- 另外 34 個只在口述中出現（`投胎轉世`、`中陰身`、`五臟六腑`、
  `五蘊`、`業力果報`、`流產`…）

所以在無字幕影片上，這套機制的覆蓋率大約是**一半**——
投影片沒提到的術語，交叉檢查沒有依據可以檢查。

**這一項是本方案的主要限制，尚未有解。**

---

## 5. 未量測

1. **真正獨立的 ASR**（非 Whisper 家族，例如 Paraformer／SenseVoice）
   會不會讓「兩者一致地錯」的 2/30 再降低。
2. **39% 的不一致率換算成人工複核成本**是否可接受。
3. **把不一致處餵給 S4 當提示**（「這幾處兩套 ASR 講法不同，請對照投影片
   判斷」）能不能提升 R13 的 recall——那是把這個訊號真正用起來的方式，
   目前只量了訊號本身。
