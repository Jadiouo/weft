## 3. 票 04 的修正正好在這裡生效

S-1 的量測：

```
全螢幕 2.4%、分離度 1.54x、1 個區段
攝影棚背景與已知的每一支都不同（最近的 zIglvjoU9vo 差 0.318，門檻 0.06）
```

**分離度 1.54x 遠低於 `MIN_MODE_SEPARATION = 3.0`**。
票 04 之前的邏輯會直接中止這支影片。

改寫後：全螢幕佔比 2.4% < `SINGLE_MODE_MARGIN` → 判定為**單一畫面模式**
→ 跳過分離度判準。那個判準對「全程都是同一種畫面」的素材沒有意義，
而純口播正是這種。

背景差異也如設計般**只記錄不中止**。

## 5. 一個沒有追的 ASR 錯誤

第一個 chunk 開頭是「歡迎來到**愛玉哲學**」——頻道叫「大问题Dialectic」，
這顯然是聽錯。沒有追原因，也沒有標準答案可比（這支沒有人工字幕，
無從算 CER）。

記在這裡是因為它提醒一件事：**這批素材沒有 ground truth**。
中醫講經那四支有手動字幕當答案，所以 R17／R20／R32 的 CER 算得出來。
這支不行——溯源檢查比對的是 Whisper 自己的輸出，
**它保證的是「chunk 沒有編造 Whisper 沒說的話」，不是「Whisper 聽對了」**。

那個區別在無字幕素材上變得重要得多。

## 6. 環境問題（不是素材問題）

第一次跑 S4a 時全軍覆沒，錯誤是
`HTTPConnectionPool(host='localhost', port=11434)`——**ollama 沒開**。

S4a 的「全軍覆沒就大聲失敗」防護正確地把它判定為環境問題並中止，
沒有靜靜產出一份沒有投影片文字的知識庫。啟動 ollama 後重跑即正常。

**但這裡有一個沒解的邊角**：這支只有 1 張代表幀，所以「全部失敗」
就是「1 張失敗」。那個防護原本是為「19 張全部失敗」設計的。
單張影片上它會把任何一次偶發失敗升級成中止。目前沒改——
在這支上它剛好抓對了，但那是運氣。
