# R26：投影片分類的判準——五個版本，沒有一個過 0.95

2026-08-08。起點是使用者的決定「把主持人的介紹現在去除」，
做下去發現要重寫的是定義本身。

**結論：改 prompt 的措辭已經到頂，停在 0.90–0.93。**
§5.2 的 0.95 維持紅燈，不調門檻、不調標註。

---

## 1. 五個版本

同一個分類模型（`ollama:gemma4:12b`）、同一批圖、temperature 0。

| 版本 | 判準 | 調校集（3 支 58 張） | 保留集（1 支 22 張） | 合計 |
|---|---|---|---|---|
| v1 | 「畫面主體為教材內容」 | 0.818 | — | — |
| v2 | 排除主講人簡介，但寫「有講者不影響判定」 | **0.636** | — | — |
| v3 | 兩步，第一步「看得到講者 → 不是」 | **1.000** | 0.909 | 0.975 |
| v4 | 只問「是不是這一集特有的」 | 0.861 | 0.952 | 0.886 |
| v5 | 兩題都要過：成段可讀 ＋ 這一集特有 | 0.885 | 0.909 | 0.900 |

**光改措辭就在 0.636 與 1.000 之間跳。** 定義的模糊確實是問題的一部分
（v1 的錯誤 100% 落在歧義類，核心類 33/33），但到了 v3 之後，
分數的變動已經反映的是**模型對指令措辭的敏感度**，不是定義還有多不清楚。

## 2. v3 的 1.000 是假的——本次最值錢的發現

v1–v3 都是拿同三支影片調出來的。那三支**全是攝影棚定鏡加全螢幕投影片輸出**，
20 張正例**沒有一張看得到講者**。所以「看得到講者 → 不是投影片」
在上面 20/20 成立——它看起來像判準，其實是這批素材的統計巧合。

新標的保留集 `2FjApOVIbUs`（第 14 集 肝臟）是**講堂實景**：
講者站在投影幕前，投影片是攝影機拍到的。

`slide_023` / `slide_024` 左半是清楚可讀的肝門靜脈解剖圖、右半是講者本人，
**兩張都是投影片**。v3 在保留集上的錯誤**恰好只有這兩張**。

> 一條在 20/20 上成立的規則，換一個場景就整組失效。
> 沒有保留集，1.000 會被當成問題解決了。

制度化：`GoldenAnnotation.holdout`，測試斷言「必須存在保留集」。
這是 §5.1(B) 第 4 條（提案演算法須與受測演算法不同）在 prompt 上的對應。

## 3. v4 為什麼修好了分割畫面卻漏掉片頭

v4 把判準換成「這些字換一集還會不會一模一樣地出現」。
邏輯上它一次涵蓋全部負例——片頭字卡、系列名稱、主講人學經歷、
佈景標語、片尾訂閱，共同點正是**每集都一樣**。

**但模型一次只看得到一張圖，它沒有辦法知道別集長什麼樣。**
所以 v4 的錯誤集中在片頭那幾張（講者＋一個大字＋一行字幕）。
v5 因此補上模型看得見的維度——**份量**：片頭是一兩個大字，教材是成段的。

## 4. 那個判準交給 CV 就成立了（跨集比對是免費的）

`cross_episode.py`：對每張代表幀，算它與**其他集**所有代表幀的最小灰階 MAE。

| | 跨集最小 MAE |
|---|---|
| 是投影片（n=26） | 最小 **7.57** |
| 不是（n=54） | 最小 0.44、中位 3.61 |

門檻取 6.0（0.44 與 7.57 之間任一值結果相同）：

- 抓到包裝 **29/54**
- 誤殺投影片 **0/26**

接在 v5 前面當前濾：

| | v5 單獨 | ＋跨集前濾 |
|---|---|---|
| zIglvjoU9vo | 0.818 | 0.864 |
| C_CFyilE-ks | 0.895 | **0.947** |
| cxrqHABhWOU | 1.000 | 1.000 |
| 2FjApOVIbUs（保留） | 0.909 | 0.909 |
| **合計** | **0.900** | **0.925** |

**仍然不到 0.95。** 剩下的錯全是**實景鏡頭**：講堂全景（MAE 75）、
攝影棚定鏡（MAE 28）、講者在講台（MAE 55）。它們每一集都不一樣——
講者的姿勢在動——所以跨集比對抓不到。

**已採納**（2026-08-08，使用者決定）。`stages/recurring.py`，
S4a 的第 0 趟。實跑四支：剔除 29 張、**誤殺 0 張**、0.900 → **0.925**，
與離線量測一致。參考影片少於 2 支時明說並跳過。

## 5. 還修掉的兩筆標註缺陷

1. **主講人簡介 5 張 T→F**（依使用者決定）。找出它們用的是**像素掃描**
   而非模型輸出的 `reject_reason`——後者是受測對象，等於拿受測者的答案改考卷。
   以人工確認過的一張為樣板，簡介頁 ≤24.31、次近者 ≥44.54，間隙 1.8x。
2. **系列標題卡跨集不一致**：`zIglvjoU9vo/slide_008` 標 T，
   但同一張卡（MAE 0.75，幾乎逐像素相同）在另兩支都標 F。改為 F。

規範化為 SDD §5.1(B) 第 8 條：**定義改了才准動標註，且不得用受測系統的輸出
去找要改哪些**；門檻紅燈時回頭調標註是明文禁止的。

## 6. 這次學到的

- **調校集上的滿分不是判準正確的證據。** 它可能只是素材的巧合。
  唯一的防線是拿一支沒參與調校的來測。
- **「邏輯上正確」與「模型判得出來」是兩回事。** v4 的判準涵蓋全部負例，
  但它要求的資訊（別集長什麼樣）根本不在模型的輸入裡。
  判準要用**模型看得見的東西**表達。
- **判不出來的部分可以換一個機制去判。** 跨集重現是同一條判準，
  交給 CV 就零誤殺——只是它也解不掉實景鏡頭那一半。

## 7. 誠實記錄的限制

- v4/v5 的判準是**看過保留集的失敗案例之後**想出來的，
  所以 `2FjApOVIbUs` 對它們而言已不是純粹的保留集。
  播放清單還有 26 支未動用，下次改判準前應該再取一支。
- 四支影片、80 張代表幀，樣本仍小。
- 只測了一個分類模型（`gemma4:12b`）。措辭敏感度這麼高，
  換模型可能比繼續改措辭有效——但那要另外量。
