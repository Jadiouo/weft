# R41：不需要門檻的分段（U&I 2001）——做到了它承諾的事，但沒有贏

2026-08-09。使用者的指示：「如果真的很差，就用你剛找到的第一個方法再試試看。」
那個方法是 Utiyama & Isahara (2001) 的動態規劃分段。

**這是探索，只在 `experiments/`，沒有進生產碼。**

---

## 0. 結論先講

| | |

## 1. 方法

U&I 把分段變成**最小成本路徑**：

```
每段用自己的字集分佈，Laplace 平滑
    P(w | S_i) = (f_i(w) + 1) / (n_i + k)      k = 全文相異詞數
整份文件的成本
    C(S) = Σ_i Σ_{w ∈ S_i} −log P(w | S_i)
```

**段數是解出來的**：切越細每段分佈越尖（成本降），但 n_i 一小分母就被 k
主導（成本升）。兩者自然平衡，**沒有門檻**。

單位沿用 S3 的偽句，詞彙用字元 bigram（與現行 ngram 一致，
中文文獻證實次詞對 ASR 錯誤較穩健）。成本增量維護：
`C = −Σ_w f(w)·log(f(w)+1) + n·log(n+k)`。

### 2.1 DP 兌現的部分

**STEM 上 DP 自動選出 16 刀，真實是 17。** 完全沒有門檻。
同一支上 ngram（α 在調校集上選的）切 34 刀，是 2 倍。

這正是 R40 §6 預測的：α 是**整支影片一個門檻**，無法分區調整；
DP 的成本函數是**全域的**，它會自己在「這裡該切」與「這裡該連著」
之間權衡。

### 2.2 DP 沒兌現的部分

講經素材上 DP 切 21／23 刀（真實 10／15），**比 ngram 還碎**。
段長最長/最短 11.3／30.5 倍（參考 4.9／4.3）。

所以「自動選段數」不等於「選得對」——它在一種素材上選得好，
另一種上選得差。**與 ngram 的強弱正好相反。**

### 2.3 兩把尺又打架了

| | WindowDiff 較好 | ±10s F1 較好 |
|---|---|---|
| `cxrqHABhWOU` | ngram | DP |
| `2FjApOVIbUs` | ngram | **DP（0.526 vs 0.333）** |
| `UiKi5-Arce4` | 混合 | ngram |

`2FjApOVIbUs` 上 DP 的 F1 0.526 是這支影片在所有實驗裡看過最好的
位置分數（R30 的 sbert 最高 0.476、ngram 最高 0.400）。
**DP 找邊界的位置能力是真的**，只是它切太多把 WindowDiff 拖垮了。

## 3. 「取各家好處」的組合——失敗

使用者的指示是把各家好處擷取下來。試的組合是：

> 候選切點 = ngram 深度分數的**所有局部極大值**（不設門檻 → 沒有 α），
> DP 在這個受限集合上找最小成本路徑（→ 沒有 prior）。
> **兩個旋鈕都被拿掉。**

結果 F1 **0.250 / 0.138 / 0.214**，比兩個親代都差。

**原因**：DP 的位置優勢來自**詞彙分佈的變化點**，那不必然落在 ngram
的餘弦相似度凹陷上。把搜尋空間限制在 ngram 的候選裡，
等於先把 DP 找對的那些邊界丟掉，再叫它從剩下的裡面挑。

> 「兩個方法各有所長 → 交集會更好」是一個**很順的直覺，而它是錯的**。
> 交集只在兩者的錯誤互相獨立時才有幫助；這裡它們的訊號本來就不同源。

保留集平均 WindowDiff 上混合法反而最低（0.424 vs ngram 0.461、
DP 0.456、一刀不切 0.466），**但那是靠切得少換來的**——
它的位置分數是三者最差。這正是為什麼 WindowDiff 不能單獨當主指標（R40 §4）。

## 4. 所以現在怎麼辦

**不換。** 理由：

- 三支影片，兩個保留集各只有一支。
- 兩把尺在三支上給出三種不同的排名。
- ngram 的 α 是在調校集上選的，DP 完全沒調過——
  **DP 在零調校下打平**這件事本身值得記，但不足以支撐替換。

**值得記下的兩件事**：

1. **DP 的位置能力在講經上明顯較強**（0.526 vs 0.333）。
   若之後要提升位置精度，這是目前最好的線索。
2. **DP 在 STEM 上自動選對段數**。R40 §6 說 α 的結構限制是
   「整支影片一個門檻」，DP 證實了那個診斷——換成全域目標就選對了。

**兩者都需要更多素材才能定案。** 目前 STEM 只有一支標註。

## 5. 限制

- `prior=0` 是**純描述長度**版本，不是 U&I 論文的完整形式
  （他們的 `P(S)` 那一項我沒有讀到公式，抓下來的 PDF 解不出文字）。
  §2 掃了 prior=100/200/400/800，全部更差（刀數掉到 1–5），
  所以**這個方向不是沒調好**，是純描述長度已經是這批素材上最好的設定。
- 詞彙用字元 bigram，**沒有掃過 n**。
- 段長 CV 這一欄裡沒有一個方案接近參考（0.44–0.55）。
  **三個方法都做不出真實的長短分佈**，只是錯的方向不同。
