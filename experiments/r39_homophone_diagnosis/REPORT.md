# R39：溯源失敗的成因——同音假說被推翻，真正的形狀是別的

2026-08-09。起因是 R27 記下的現象：Whisper 把「座標」聽成「做標」，
S4c 寫 block 時自己改對了，於是對 `transcript_raw` 的比對失敗——
**判定是對的**，但成因被歸進「真的溯不到」，而那一欄正是拿來判斷
內容有沒有問題的。R27 當時的推測是「這可能佔不少」。

**量完的結論是：不是。**

---

## 0. 結論先講

| | |
|---|---|
| **同音替換佔比極低** | 拼音比對比字面只多 **+0.004**，通過組與未通過組**一模一樣** |
| **尺是準的，不是量錯** | 純同音案例 0.75 → **1.00**；R27 那個真實案例 0.0 → 0.18 |
| **真正的訊號在覆蓋率本身** | 未通過組字面覆蓋 **0.033**，通過組 **0.420**（STEM） |
| **數學符號不是解釋** | 未通過 93.8% 含符號，但**通過組也有 77.4%** |
| **手讀三段：三個成因，沒有一個是編造** | §3 |
| **但也不是「檢查沒用」** | 其中一段確實編出了講者沒說過的符號，見 §3.1 |

## 1. 怎麼量的

447 個有判定的 block（8 支影片）。每個 block 對它自己那一段的
`transcript_raw` 算兩種 3 字窗覆蓋率：

- **字面**：漢字 3-gram 直接出現在逐字稿裡
- **拼音**：同一個 3-gram 轉成不帶聲調的拼音後出現

拼音明顯高於字面 ⇒ 內容在逐字稿裡**聽得到但寫不同字** ⇒ 同音替換。

**對照組**：同一個 block 對上**同支影片離得最遠的另一段**。
內容無關，但語者、主題、ASR 特性都一樣——比隨機字串公道得多。
（R23／R37 各栽過一次：對照組出錯或缺席時會偽裝成訊號。）

## 2. 結果

| 組別 | n | 字面 | 拼音 | 增益 | 對照組增益 |
|---|---|---|---|---|---|
| 未通過 | 30 | 0.061 | 0.064 | **+0.004** | −0.043 |
| 通過 | 417 | 0.456 | 0.460 | **+0.004** | −0.369 |

**增益在兩組完全相同**，而如果同音替換是失敗的成因，未通過組的增益
應該明顯較高。它沒有。

尺本身有效——先驗過才敢說是空結果：

```
純同音案例  「座標系的原點」vs「做標系的原點」   0.750 → 1.000
R27 的實例  「…坐標系B中的點P…」vs「這個做法系統…」 0.000 → 0.182
```

對照組也證明這把尺不是「什麼都說找得到」：通過組換一段比，
覆蓋率掉 **−0.369**。

未通過組的對照增益只有 −0.043，因為它們的字面覆蓋已經在地板上
（0.061）——**掉無可掉**。這本身就是線索。

### 2.1 數學符號的假說也不成立

R36 曾記「模型把口說的『四乘四』寫成 `4x4`、『R 一一』寫成 `R₁₁`，
字元 n-gram 對這種正規化完全無能為力」。量下來：

| 素材 | 組別 | n | 含數學符號 | 平均字面覆蓋 |
|---|---|---|---|---|
| STEM | 未通過 | 16 | 93.8% | **0.033** |
| STEM | 通過 | 168 | 77.4% | **0.420** |
| 其他 | 未通過 | 14 | 21.4% | 0.092 |
| 其他 | 通過 | 249 | 24.5% | 0.480 |

符號率 93.8% vs 77.4% 有差距，**但通過組也有四分之三帶符號**——
它不足以區分。真正拉開的是覆蓋率本身（0.033 vs 0.420），
差了一個數量級。

## 3. 手讀三段

覆蓋率說「這些 block 的內容不在自己那段逐字稿裡」，但沒說為什麼。
那只能讀。抽三段：

### 3.1 `UiKi5-Arce4#023#b01`——**部分屬實，但編了符號**

```
block： 旋轉變換具有非交換性，例如 R₁₁(a) 和 R₁₂(β) 的乘積不等於
        R₁₂(β) 和 R₁₁(a) 的乘積。旋轉矩陣可以表示為 3x3 矩陣…
逐字稿：…旋轉本身是不可以交換　旋轉矩陣是個3乘3的…
```

「不可交換」「3乘3」**都在逐字稿裡**，只是寫法從口語換成書面。
但 `R₁₁(a)`、`R₁₂(β)` 這組符號**講者從頭到尾沒有說過**——
他說的是「對哪個軸轉幾度」。

**這一筆的失敗是對的。** 檢查抓到了真東西。

### 3.2 `UiKi5-Arce4#039#b02`——**分段把解釋切斷了**

```
block： 後乘法意味著每次轉換都相對於前一個轉換框架進行…
逐字稿：…我們會使用前乘還是後乘　我會選A乘B呢
```

逐字稿**問了問題就結束了**，答案在下一段。這是**歸屬錯**，
而且根源是分段——R37 量到 STEM 上分段刀數是真實邊界的 3.4 倍，
切在解釋中間是可以預期的。

### 3.3 `xBfyWwYylSA#024#b01`——**內容來自投影片，卻拿逐字稿去比**

```
同段的「經文原文」block： Euler(φ, θ, ψ) = Rz(φ)Ry(θ)Rz(ψ)
失敗的 block：           首先對Z軸旋轉φ，然後對新的Y軸旋轉θ，最後對最新的Z軸旋轉ψ
逐字稿：                 …RZ的Y…第三個可不可以是Z…RZ RY RY當然不可以…
```

ZYZ 這個順序**寫在投影片上**，講者當下在討論「哪些軸序合法」。
block 講的是投影片內容，`provenance_kind` 卻是 `transcript`。
**來源型別判錯**，不是內容有問題。

## 4. 所以那個閘門在擋什麼

三段、三個成因，**沒有一個是憑空編造整段內容**：

| | 成因 | 檢查判得對嗎 |
|---|---|---|
| #023 | 書面化 + **編出講者沒說的符號** | **對** |
| #039 | 分段切斷解釋，答案在下一段 | 對（歸屬錯），但根源在 S3 |
| #024 | 內容來自投影片，來源型別判錯 | **不對**——比錯來源了 |

**三個裡有一個是檢查本身不適用。** 這與 R22 的「一半的未通過不是
內容問題」方向一致，但成因不同——R22 那批是中醫講經。

**沒有據此調整閘門。** per-video 閘門的取捨是 known-risks R23 的
未決事項，需要使用者決定「寧可漏放還是寧可錯放」，那不是實作問題。
這份報告只是把「被擋掉的到底是什麼」講清楚，好讓那個決定有依據。

## 5. 限制

- **手讀只有三段**，而且是我自己讀的（我也是寫 block 的那個模型的同類）。
  §3 的判斷沒有第二個人複核。
- 3 字窗是**選定的，沒有掃過**。2 字窗會更寬鬆、4 字窗更嚴，
  結論對窗長的敏感度沒量。
- 拼音比對不帶聲調（沿用 `corrections.py` 的 `pinyin_key`），
  所以它會把不同聲調的字算成同音——**這讓同音假說更容易成立**，
  而它還是沒成立。這個方向的偏誤對結論有利，不是不利。
- 未通過只有 30 個。§2.1 分素材之後每格 14–16 個，
  那些百分比的誤差很大。
